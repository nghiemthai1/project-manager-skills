# Communication Plan: software example

Fictional training scenario. Values and thresholds are examples, not defaults for real projects.

## Proposed Relay plan

Mina prepares a brief sponsor update for Ada at the agreed control cadence, using the same scope, cost, and schedule evidence as team coordination. The sponsor version emphasizes tradeoffs and decisions; the team view adds current dependencies and action owners.

Lena receives the actual security evidence needed for acceptance, not a green summary. Theo receives operational procedures and handover evidence. Pilot administrators receive the information needed to participate in validation and later rollout; no announcement is sent before authorization.

A failed release gate triggers an immediate decision brief rather than waiting for the next routine report. The plan lists these arrangements as proposed until the participants confirm them.
