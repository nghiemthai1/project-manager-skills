# Project Charter: software example

Fictional training scenario. Values and thresholds are examples, not defaults for real projects.

## Proposed charter before 2 October

**Purpose:** enable one enterprise pilot tenant to use SAML access with observable audit events and recoverable service access.

**Included:** SAML login, audit events, recovery access, operator guidance, reversible rollout. **Excluded:** SCIM provisioning. **Target:** pilot 30 October, subject to integrated planning and sponsor approval.

Ada is sponsor, Mina coordinates delivery, Priya owns product priorities, Lena accepts security evidence, and Theo accepts service handover. The charter requests confirmation of the funding and delivery baseline; it does not call the draft approved.

Success requires usable pilot access and accepted security/operational evidence. Priya owns a later benefit review, whose measures must be agreed rather than invented as a guaranteed adoption increase.

On 2 October, D-001 establishes B1. That later approval is attached to the charter history.
