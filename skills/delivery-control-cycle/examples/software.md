# Relay delivery control cycle

Fictional training scenario, 16 October 2026. Mina prepares a dated control packet using D-001/B1, cost inputs through this date, the audit forecast, I-001 and current acceptance gaps. No later approval is imported.

| Phase | Actual control output | Unresolved evidence / exit state |
|---|---|---|
| Review basis | B1: 30 October pilot, 100k performance budget, 10k reserve outside BAC | Prior action-completion evidence not supplied |
| Reconcile | Interface need 20/forecast 22 October; I-001 environment unavailable; R-001 compatibility uncertainty distinct | Usable input/receiver state and environment restoration evidence needed |
| Reforecast | CPI 40/48=0.8333; conditional EAC 120k; final-date forecast not validated | Current ETC, constrained schedule and recovery evidence needed |
| Decide | Prepare scope/funding/recovery options for Ada | No baseline change or additional spend authorized as of 16 October |
| Communicate/verify | Executive report highlights funding intervention and pilot risk; retain technical detail in evidence packet | Proposed review timing/accepted action owners need confirmation |

The 120k forecast exceeds the 100k baseline by 20k and original 110k envelope by 10k. Even if reserve were released, additional authority would be needed for that scenario. The two-day interface gap is local; no precise pilot slip follows without the network, calendar, validation and capacity review.

Prior actions cannot be closed merely because someone reports progress. For I-001, request evidence of a usable environment; for R-001, compatibility proof remains a separate question. For readiness, a planned recovery test remains planned until executed and accepted within the relevant remit.

At the later review, actual CR-001 on 19 October changes scope and cost prospectively. Update the current scope/B2 view and link the decision; retain the 16 October packet against B1. Do not put a 3 November date into that cost decision: D-004 changes the date separately on 29 October.

The 28 October missing recovery demonstration triggers an exception review before the planned pilot. A routine cadence cannot justify waiting past the useful decision window. The response checkpoint is applicable evidence and an actual authority decision, not another dashboard update.

**Repair:** “Update every document to the newest date and call aligned” destroys history. The corrected cycle reconciles current views while retaining the previous baseline, cutoff and exact decision scope.
