# Northstar: context dump followed by one decision

Fictional facilitation example. The user pastes a migration rehearsal summary: attachment counts match, some links do not resolve, restore has not been demonstrated, and operations needs proof before handover. They request a draft workshop plan now rather than a live interview.

## Respect the requested mode

Use the single-shot path. Do not insist that the user first choose Guided, Context dump or Best guess: the context and request already select a context-dump draft. State that the workshop plan is proposed and no participant agreement exists yet.

## Proposed 40-minute plan

| Phase | Exercise | Output |
|---|---|---|
| 0–10 min | Read the supplied observations back and separate findings from assumptions | Matching counts, broken relationships, absent restore evidence; no invented root cause |
| 10–20 min | Ask what each acceptance owner needs to judge the affected workflow | Proposed criteria and named authority gaps |
| 20–30 min | Compare responses: repair/retest, investigate missing cause, or resolve environment/capacity blocker | Numbered recommendation with conditions |
| 30–40 min | Read back the selected response and confirm exact actions | Owner acceptance, date if agreed, evidence and next review |

## Example exchange at the decision point

Facilitator: “The link failure is observed, but its cause is not established. Which next step fits the evidence: 1 investigate a representative failed case, 2 apply and verify a known fix, or 3 resolve missing access before either can proceed?”

Participant: “1, then 2 if we reproduce it.”

Facilitator: “Record investigation first, with repair conditional on the result. Who can accept the investigation assignment?” This acknowledges the combined choice without converting an option into a commitment.

## Pause and resume

If the user says “stop until the vendor joins,” preserve the current observations, unchosen options and pending assignment question. Resume at that point only when asked. Do not continue interrogating the user or infer vendor consent from absence.

**Repair:** “All participants agreed to cut over” cannot be derived from a discussion of next tests. Close with actual decisions, proposed actions and unresolved acceptance, each separately labeled.
