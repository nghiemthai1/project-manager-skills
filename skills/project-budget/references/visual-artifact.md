# Baseline, actual and forecast comparison

Read this when the request calls for a graphical artifact. A chart is optional when the existing table or discussion already answers the decision.

## Source and choice

Capture: **currency and scale; as-of date; baseline version and approval; BAC; PV/EV/AC and earning rule; category actuals, unspent commitments and ETC; EAC method; reserve ownership; funding envelope; decision authority**. Preserve null remaining amounts as unknown.

Use aligned nonstacked bars for comparable amounts and separate funding bridges. BAC, AC and EAC overlap conceptually and must not be stacked as additive spend. Distinguish management reserve from the performance baseline.

## Interpretation

Compare EAC with both BAC and the funding envelope, with each difference labeled. A forecast does not authorize spending or imply calendar days late.

## Delivery standard

Preserve a source snapshot and mapping from literal IDs/fields to the displayed marks. Put the title, scope, as-of date, units, assumptions and unknowns next to the visual. Use direct labels plus shape/text states; color cannot be the only meaning. Do not fabricate coordinates, dates, scores or confidence to make a chart complete.

Choose static SVG for a shareable diagram, self-contained HTML when filtering or inspection helps, or a table when it communicates the decision better. Interactive output needs visible filter scope/counts, reset, keyboard access and persistent details; a phone view needs readable cards, a focused slice or a deliberate scroll region. Avoid tiny desktop diagrams on phones. Use the [offline renderer](renderer.md) for the maintained interactive workflow.

Deliver editable source plus a full accessible cost register. Label exports as source, full draft or current visible draft and preserve hidden-data caveats. Browser edits are local proposals: recalculate supported formulas, retain before/after history, keep source exports immutable and flag the selected forecast and decision options for revalidation. Open the actual artifact, compare values and relationships with the source, inspect desktop/portrait/landscape and test controls, editing and downloads. If rendering is unavailable, deliver a labeled source draft and say visual inspection was not performed.
