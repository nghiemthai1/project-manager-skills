# Project Health Diagnostic: software example

Fictional training scenario. Values and thresholds are examples, not defaults for real projects.

The approved scope/funding changes do not establish release readiness. Recovery access has not been demonstrated, and Lena rejects readiness. That is the decisive condition for the planned 30 October pilot, regardless of completed coding or the revised budget.
