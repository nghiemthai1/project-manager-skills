# Cedar delivery approach — recommendation, 22 October 2026

**Use hybrid delivery: weekly evidence-producing rehearsals inside controlled migration scope, funding, and release gates.** A fixed cutover constrains the plan but does not make attachment behavior known. Rehearsal feedback is already available weekly, so defining every implementation task now would imply knowledge the team does not have.

| Option | Fit | Tradeoff and disposition |
|---|---|---|
| Predictive | Appropriate for the cutover sequence, vendor interfaces, funding control, and operational handover | Use for known coordination; a fully fixed detailed plan would delay learning about broken links and restore |
| Agile | Useful for short remediation/rehearsal increments with observable feedback | Use learning practices; unconstrained backlog changes would jeopardize the authorized scope/date. No evidence supports adopting a particular named framework |
| Hybrid | Matches uncertain migration behavior plus a controlled cutover | Recommended; make the boundaries explicit so adaptive task planning is not mistaken for authority to change commitments |
