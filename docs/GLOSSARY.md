# Project management glossary

| Term | Meaning in this library |
|---|---|
| Acceptance | An authorized judgment that the applicable deliverable conditions are satisfied |
| Actual | An observed result or incurred cost, with a reporting cut-off |
| Assumption | An unverified premise used in planning, with a validation need |
| Baseline | An approved comparison point for scope, schedule, or cost |
| BAC | Budget at completion: the performance budget used in earned value |
| Change request | A proposal to alter an agreed control boundary, with impact and a decision record |
| Commitment | A responsibility or promise accepted by an authorized person or team |
| Contingency | A planned response or allowance for identified uncertainty, under stated authority |
| Critical activity | An activity with zero total float in the stated unconstrained CPM model |
| Critical path | A longest dependency-constrained route to the modeled project finish; ties can exist |
| CV | Cost variance, EV minus AC, in the project's value unit |
| DACI | Driver, Approver, Contributors, Informed: roles in a particular decision |
| Dependency | A required deliverable or decision linking work across a boundary |
| Duration | Elapsed work time under a stated scheduling model and calendar |
| EAC | Estimate at completion: a forecast of total cost, not approval to spend |
| Effort | Person-time consumed by work, distinct from elapsed duration |
| EV / PV / AC | Earned value, planned value, and actual cost, aligned to one cut-off and baseline |
| Evidence | An identifiable observation, source record, or calculation supporting a claim |
| Forecast | A current expectation with a method, assumptions, and as-of date |
| Gate | A decision point with explicit conditions and evidence requirements |
| Handover | Accepted transfer of defined responsibilities and supporting materials |
| Hypercare | A bounded enhanced-support arrangement with owner and exit criteria |
| Issue | A present problem requiring a response or disposition |
| Local delivery margin | Needed-by date minus expected-delivery date using a stated calendar; not total float |
| Management reserve | Separately controlled allowance whose treatment and release authority are explicit |
| OKF bundle | The preserved v0.2 Markdown meeting-memory format used by the meeting skill |
| Outcome / output | Outcome is the change enabled; output is the delivered artifact or capability |
| RACI | Responsible, Accountable, Consulted, Informed: responsibilities for defined work |
| RAG | Red/amber/green shorthand interpreted against stated tolerances and evidence |
| Residual risk | Exposure remaining after a response, with acceptance authority where required |
| SPI / CPI | EV/PV and EV/AC; ratios whose interpretation depends on valid inputs |
| Sprint Goal | The coherent objective of a Sprint; selected work supports a team forecast |
| SV | Schedule variance in earned value, EV minus PV; measured in value, not days |
| Target | A desired result or date that may not yet be feasible or approved |
| Total float | Permitted activity movement within the stated integrated scheduling model |
| Traceability | Links connecting rationale, requirements, deliverables, verification, and acceptance |
| Verification | Checking a defined condition against evidence, distinct from authorized acceptance |
| WBS | Work breakdown structure: a hierarchy covering agreed project scope without overlap |

See [Frameworks](FRAMEWORKS.md) for selection guidance and limits.
